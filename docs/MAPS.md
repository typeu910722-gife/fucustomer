# 地圖（店面種類）與如何新增

目前有 **21 種店**，都可以在「自由營業」選擇、開自己的店時選擇，每日挑戰也會每天換一種。職涯第 7 章在前 4 種非便利商店見習，第 8–10 章（`docs/STORY-DESIGN.md`）每一班換一種新店，主角是那種店的**招牌奧客**。

招牌奧客只會出現在自己的店（自由營業、自己開店、每日挑戰）；職涯班次可以指定任何奧客（例如 10-6「圖鑑大集合」在便利商店一次出現七種）。所有奧客一樣可以抓起來丟出門。

### 招牌奧客是怎麼做的（`shared/sigkarens.ts`）

每個招牌奧客是一筆資料，套用 7 種行為樣板之一，再加上參數：

| 樣板 | 行為 | 用到的店 |
|---|---|---|
| `till` | 正常購物，到收銀台卡住不結帳，直到你做某個動作（可要求手上拿著拖把／熱食，可要做好幾次） | 加油站、雞排店、郵局 |
| `haggle` | 卡在收銀台吵，火氣自己一直升；每次「堅持」降火，或花錢／換個方式打發；火氣滿了大鬧 | 藥局、飯店 |
| `camp` | 走到一個點（貨架前或地圖的 `campSpots`）蹲著／坐著，每幾秒造成效果 | 書店、超市、咖啡廳、電影院、健身房、牛排館 |
| `roam` | 在貨架間亂逛，每幾秒造成效果（可設定「看到店員就跑」） | 藥妝店、麵包店、寵物店 |
| `redo` | 在取餐區等現做的東西，前幾次交付都說不對；可用說明動作解決 | 美髮院 |
| `sneak` | 要靠近才看得到，把貨架上的東西塞進包包；放他走店裡要賠 | 火鍋吃到飽 |
| `refund` | 在服務台要求退款，倒數結束就被迫退款；可檢查或直接退 | 3C 賣場 |

效果：`stock`（拿走貨架商品）、`mess`（地上髒污）、`money`（每次扣店裡現金）、`aura`（他附近的客人耐心掉 1.8 倍）、`queue`（全店排隊的人耐心掉 1.5 倍）。每次效果也會讓混亂度 +1。
其他參數：`presses`（要做幾次）、`dur`（每次要講幾秒）、`need`（手上要拿什麼：`mop`／`coffee`／`meal`／`box`）、`alt`／`altNeed`／`altCost`（第二種解法）、`relocate`（每做一次他就換位置）、`flee`、`hidden`、`buys`（處理完會買東西去排隊）、`life`（撐多久店家就輸）、`failMoney`。

互動的動作只有兩個（`sigAct` 主要、`sigAlt` 第二種解法），按鈕文字從資料來，所以客戶端（`client/src/game.ts` 的 `sigCandidate`）和模擬玩家（`shared/bot.ts`：先去拿需要的東西再處理）都不用為每個奧客另外寫。
頭上的 3D 小道具在 `client/src/karen-props.ts`（`buildKarenProp(kind)`）。

**新增一個招牌奧客**：在 `SIG_KARENS` 加一筆資料（名字、圖示、提示、處理方法、樣板與參數、成功／失敗訊息）→ 在那種店的地圖檔 `karens` 加上它（camp 樣板要給 `campSpots`）→ 在 `karen-props.ts` 加一個小道具 → 跑 `npm test`：`tests/sigkarens.test.ts` 會自動對每個招牌奧客檢查「會出現、會擋路／搗亂、用指定動作可以解決、放著不管店家會輸」，並讓一個不會抓人的模擬玩家實際上班，確認它會處理。

## 新增一種店（例如：雞排店、藥妝店、書店）

1. 複製一個最像的檔案，例如 `cp shared/maps/breakfast.ts shared/maps/chicken.ts`。
2. 修改內容（每個欄位在 `shared/maps/types.ts` 都有說明）：
   - `id`（英文小寫，存檔用，不要改來改去）、`name`、`icon`、`desc`
   - `sign` 招牌文字與顏色、`poster` 後牆海報兩行字
   - `theme`：地板（`tile` 磁磚／`wood` 木頭／`concrete` 水泥）與牆、腰帶、強調色、櫃台、貨架顏色
   - `products`：三條商品線的名稱、售價、進貨價、顏色、外觀（`can` 罐、`bottle` 瓶、`box` 盒、`flat` 扁盒、`cup` 杯、`shirt` 上衣、`pants` 褲子、`bag` 包）
   - `shelves`：三個貨架的位置。`shelf`／`rack`（衣架）是中島，要「東西向較長」；`fridge`／`wallshelf` 靠東牆或西牆，要「南北向較長」
   - `coffee`、`meal`：兩個工作站（名稱、動作、價格、位置），不需要就設 `null`；工作站南邊 0.6 公尺要留空給店員站
   - `counter`、`registers`、`queue`（排隊點，第一個靠近收銀台）、`pickup`（取餐區）、`complaint`（客訴點）
   - `decor`：家具，可用 `table`、`bar`、`plant`、`atm`、`display`、`fitting`（試衣間）、`mannequin`（假人）
   - `playerSpawns`、`wander`（奧客閒晃的空地）
   - 選填：`karens`（這種店專屬的奧客，會加進自由營業／自己開店／每日挑戰）、`tryOnSpots`（試穿狂站的位置）、`campSpots`（camp 樣板奧客坐的位置）、`rope`（排隊紅龍）、`goalScale`（每日挑戰目標倍率；單價高的店要調高，例如服飾店 2.7）
   - 收銀台、排隊、取餐區用標準位置的話，可以直接用 `shared/maps/common.ts` 的 `STD_FRONT`、`COFFEE_BOX`、`MEAL_BOX`、`WEST_TABLES`
   - 新的專屬奧客：優先用上面的招牌奧客資料（`shared/sigkarens.ts`）；真的需要新行為才在 `shared/sim.ts` 另外寫
3. 在 `shared/maps/index.ts` 的 `MAPS` 加上它。
4. 跑 `npm test`：`tests/maps.test.ts` 會自動檢查每張地圖——家具有沒有互相重疊或插進牆裡、排隊點、收銀台、取餐區、奧客位置等有沒有卡在家具裡、貨架／收銀台／工作站／倉庫是不是走得到，並讓模擬玩家實際經營一整天（有服務到客人、有營業額）。
5. 每日挑戰的 `goalScale`：用模擬玩家在同樣條件下比較「這種店的營業額 ÷ 便利商店的營業額」來定（第 8–10 章新店就是這樣定的，再用 `npm run balance daily` 確認）。
6. 跑 `node tests/e2e/maps.mjs`（需先 `npm run build && npm start`）會把每種店截圖存下來，用眼睛確認外觀。

固定不變的部分（所有店共用）：24 × 16 公尺的店面、南牆的門（x 10.5–13.5）、西北角倉庫與三個貨箱、西牆的拖把架、門口外的街景。

## 目前限制

- 多人連線：建立房間時可以選店面種類（主選單「建立房間」左邊的選單）；加入的人會先向伺服器查詢房間的種類再建畫面。伺服器同時開多個不同種類的房間時，每個房間在更新前切換到自己的地圖（第 12 輪）。
- 職涯主線 1–6 章在便利商店，第 7–10 章在其他店（10-6 回到便利商店）。
- 每種店的經營數值（售價、現做比例、招牌奧客的時間與次數）只用模擬玩家調過，**還沒有經過真人試玩調整**。
- 新店的 3D 外觀沿用現有家具種類（桌子、吧台、展示台、植物、ATM、假人），健身器材、電影座椅等是用展示台／吧台代替；招牌奧客的頭上標籤與手上道具要由畫面程式接上（`SIG_KARENS[kind].tag`、`buildKarenProp(kind)`）。
