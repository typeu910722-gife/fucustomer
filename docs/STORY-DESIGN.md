# 故事、經濟與法庭系統設計

依使用者 2026-10-19 的方向設計。所有人物、公司、法院都是虛構的，以搞笑、諷刺為主，不指涉真實人物。

## 主線故事：打工人的存錢開店夢

| 角色 | 說明 |
|---|---|
| 你 | 認真的打工人，夢想是存夠錢開一家「不用看老闆臉色」的店 |
| 錢董 | 黑心老闆。營業額越好，扣薪理由越多（制服清潔費、收銀短少、打卡晚 1 分鐘、空調電費分攤……） |
| 阿芬姐 | 資深同事，教你處理奧客，偶爾偷偷提醒你哪個奧客「有背景」 |
| 小林 | 地方記者。被你直播爆料的案子，他會追蹤報導 |
| 奧客之王 | 第 6 章魔王 |

每章開頭與通關後有對話場景（第一次才播放，可跳過）。第 6 章結局：你辭職，帶著存款走向「自己開店」。

## 經濟：小費自己留、薪水被硬凹

每班結算的錢包入帳：

```
時薪（依章節）＋ 營業獎金（營業額 12%）       ＝ 應得薪水
                               － 錢董硬凹（15–45%，附理由；3 星時錢董心情好扣比較少）
＋ 小費（顧客給的，100% 你的）
＋ 請出門獎金
－ 法院罰款（如果有）
＝ 實際入帳（存款）
```

存款用途：買裝備、（第二階段）開自己的店。

## 出手（毆打）與「佔不佔理」

- 新動作「出手」（電腦 X、手把 RT、手機「揍」按鈕），正職店員 Lv6 解鎖。打中會讓對方暈 2.5 秒。
- **佔理（正當防衛）**：對方正在失控——退貨大鬧怒氣 ≥ 70、奧客先推了你（6 秒內）、或是奧客之王。打失控的奧客兩下會被制伏、自己離開。
- **不佔理**：對方沒有失控就先動手、打到一般顧客（最嚴重）。會記一筆「事件」，口碑也會掉。
- **有背景的奧客**（第 2 章起約 12%，走近時頭上出現「💼 好像有背景」）：不管佔不佔理，打了都會有人報警。
- **抓不動的奧客**（第 3 章起約 20%，體型特別大，「🏋 抓不動」）：要先揍暈或用拖把旋風弄暈，才抓得起來。
- 有任何「不佔理」或「打到有背景的人」→ 下班時警察來店裡，帶你去**審訊**。

## 審訊（法庭）

1. 警察說明案情（列出每一筆事件，佔理的會標示）。
2. 抽到一位法官：
   - **明理法官**：三題問答，誠實配合可爭取最低罰款；佔理的事件會被撤銷。
   - **恐龍法官**：不管你說什麼都可能被重判（「表情不夠悔改，罰款加倍」）。判決後可以抗爭：
     - 認罰。
     - **當庭開直播**：輿論壓力 55% 改判最低罰款；45% 被認定藐視法庭，罰款 +50%。
     - **提出上訴**：付律師費，換一位法官重審。
     - **調出監視器畫面**：如果每一筆事件其實都佔理，直接無罪；否則沒有用。
     - **當庭裝暈**：30% 延期（罰款減半），70% 被識破（罰款 +20%）。
   - **瞌睡法官**：判決靠運氣；可以「大聲咳嗽叫醒他」重新開庭一次。
3. 罰款（基準：每筆不佔理 $100、打一般顧客 $250、有背景再 +$100，隨章節 +15%；恐龍法官 1.3–2 倍）從存款扣（不會變負數）；紀錄留在職涯「紀錄」分頁（審訊次數、罰款總額、無罪次數）。

## 第二階段：自己開店（下一輪）

- 解鎖：通過第 6 章，且存款 ≥ 開店基金。
- 用存款當資本，經營自己的店（沿用自由營業的日結系統：租金、進貨、升級）；換你當老闆，可以選擇對員工「佛心」或「黑心」。
- 有機會倒閉：連續 3 天日結現金為負或口碑歸零 → 店收掉，投入的錢沒了，回去打工重新存。

## 第三階段：好友的店（需要線上伺服器）

- 每家自己的店有「店碼」。可以到朋友的店**搗亂**（扮演奧客，在時間內製造混亂）。
- 下線前要記得**鎖店門**；沒鎖門的話，朋友可以在你離線時衝進去搗亂，回來時看到損失報告。
- 這需要一台一直開著的公開伺服器來保存每家店的狀態與好友關係。目前只做在本機伺服器上；**正式上線需要選定主機（會有費用），要先跟你確認**，不會自行註冊付費服務。
