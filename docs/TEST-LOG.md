# 實測紀錄

分類定義（彼此不互相冒充）：

- **模擬玩家**：`shared/bot.ts` 程式化玩家，只讀快照、只送正式協定訊息。
- **多開（同機）**：同一台機器上多個真實客戶端（WebSocket 客戶端或多個瀏覽器分頁/環境）連到真實伺服器程序。
- **跨網路**：不同網路（例如手機 4G ＋ 家用 Wi-Fi）連到公開伺服器。
- **跨平台實機**：iOS 實機、Android 實機、Windows/Steam 實機。
