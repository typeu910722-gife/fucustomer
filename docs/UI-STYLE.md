# 介面風格（第 13 輪）

- 方向：卡通遊戲風。奶油色面板、深紫粗外框、可以「按下去」的立體按鈕（底下 5px 陰影，按下時往下沉）、斜紋背景。
- 橫向優先：主選單左邊標題／右邊選單；職涯畫面左邊職級與分頁、右邊內容。手機直拿會出現「請轉橫向」畫面。高度 520px 以下（手機橫拿）自動縮小間距。
- 字型：justfont「粉圓」（SIL Open Font License 1.1，可商用，授權檔 `client/public/fonts/OFL-huninn.txt`）。只保留遊戲用到的約 1,080 個字（205 KB）。**新增文字後要跑** `python3 scripts/font-subset.py`；`tests/font.test.ts` 會檢查有沒有漏字。
- 顏色變數都在 `client/index.html` 的 `:root`：`--ink` 外框、`--cream` 面板、`--accent` 主要按鈕（紅）、`--good` 綠、`--warn` 黃、`--info` 藍。
- 按鈕樣式：`.btn`（白）、`.btn.primary`（紅）、`.btn.good`（綠）、`.btn.warn`（黃）、`.btn.info`（藍）、`.btn.purple`、`.btn.small`、`.btn.hero`（大）。

## 手機橫向 HUD 分區（第 29 輪，844×390 為準）

上班中的畫面分成固定的區域，短暫訊息只能出現在「訊息欄」，**互動提示和觸控按鈕永遠不會被蓋住**。
排版由 `client/src/hudq.ts` 每次 HUD 更新時重算（依實際元件位置，不寫死座標，平板也適用），樣式在 `client/index.html` 的「transient stack」段落。

| 區域 | 位置 | 放什麼 |
|---|---|---|
| 左上 | 小地圖，下面接庫存／隊友面板 | 手機右邊是按鈕，所以庫存／隊友放在小地圖下面（桌機在右上） |
| 上方中間 | 班表列（時間、營業額、混亂度）；準備階段下面是「開始上班」 | 固定元件 |
| 右側整欄＋右上 | 觸控按鈕（互動、次要、跑、標記、抓／揍／旋風／退散、☰💬🛒） | **保留給按鈕**，任何提示都不能進來（透明的也不行） |
| 左下角（寬 24%、高 40%） | 搖桿、情緒爆發量表 | **保留給搖桿** |
| 中間上方「訊息欄」`#hq` | 班表列下面、左欄右邊、按鈕左邊、互動提示上面的長方形 | 所有短暫訊息，由上往下排（見下） |
| 中間（準星下方） | 互動提示 `#prompt` | 底部貼在體力條上方，往上長；寬度限在搖桿角和按鈕之間，太長就換行 |
| 下方中間 | 體力條、音效字幕 | 字幕在同一欄內，一則一行（太長用「…」），最多兩則 |

訊息欄的順序就是優先順序（`#hq` 裡的 DOM 順序）：

1. 新奧客卡／第一次來這間店的卡（`#introcard`）
2. 提示列（教學、第一次空貨架提示）＋手機的「跳過教學」
3. 奧客警告（`#alert`）
4. 常客奧客卡（`#arccard`）
5. 發票對獎魔人的「跟上」提示
6. 停電／尖峰人潮
7. 劇情對話泡泡（手機）
8. 吐司訊息：最新的在上面，手機最多 2 則、桌機 3 則；同樣的字再出現會取代舊的
9. 隊友快速訊息（手機，最新 2 則）

規則：
- 放不下的就先收起來（不顯示），等有空間再出現，**從最下面的開始收**；放不下時卡片先縮成只有標題一行、警告先縮成第一行。
  如果卡片佔位置害警告被收起，卡片會自動縮成一行讓警告留著。
- **卡片一次只出現一張**（一個佇列）：同時來好幾個新奧客就輪流出現，每張出現時單人模式才暫停 2 秒；新奧客卡優先於常客卡
  （常客卡會先讓位，之後帶著剩下的時間回來）。卡片的時間只在它真的看得到時才算。
- 手機上的卡片是**短版**：標題＋一行「處理方法」，右上角 ▼；點一下展開全部（時間暫停，展開時可以用到班表列那一塊），再點一下收回。
- 互動提示優先度最高：提示變高時，訊息欄自己變矮。
- 字級 130% 在 390px 高的手機上，訊息欄常常只放得下 1～2 樣（例如卡片標題＋警告），吐司訊息在忙的時候會被收起來。這是刻意的取捨：提示和按鈕不被蓋住比較重要。
- 準星會畫在訊息欄上面（訊息欄經過畫面中央時仍看得到準星）。
- 找零小遊戲（`#qte`）出現的那幾秒，訊息欄暫時隱藏（它用的是同一塊位置）。
- 測試：`tests/e2e/round29a.mjs`（844×390 觸控模擬，字級 100%／130%，一次湧入 5 個奧客＋多則吐司＋卡片＋字幕＋跟上提示，10 秒內每 250ms 檢查按鈕和提示沒被蓋到超過 2px、沒有東西跑出畫面；另有 1280×720 桌機檢查）。這是瀏覽器模擬，不是實機。

桌機：同一套規則，訊息欄在班表列下面、左邊小地圖和右邊庫存面板之間、互動提示上面（警告和提示列因此從畫面下方移到上方）；劇情泡泡、隊友訊息、跳過教學鈕、找零小遊戲維持原位置。
