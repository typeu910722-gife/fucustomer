# beta-pages

Source copies of the hand-written pages in main's `beta/` folder (fucustomer.yzprojecttw.com/beta/).
When updating beta: copy the Vite build (`dist/`) into `beta/`, then copy these files on top, plus the APK as `fucustomer-beta.apk`.
The beta build must be made with `VITE_SERVER_URL=wss://fucustomer-game.typeu910722.workers.dev/ws`.
